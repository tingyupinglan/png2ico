# png image file to icon file
This is a simple powershell script,it can convert a png image file to icon file.
it can automatically convert square images into rounded rectangle icons with transparent alpha channel.
# how to use
1. Open the terminal
2. Drag the script into the terminal and hit Enter
3. Enter the full path of your target PNG when prompted, or drag the file into the terminal and press Enter
4. The converted ICO will be saved alongside the source PNG within a few seconds
